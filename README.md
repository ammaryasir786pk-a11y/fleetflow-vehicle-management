# FleetFlow Vehicle Management

A Windows desktop app for managing fleet operations.

## Download

**[Download the latest Windows build](https://github.com/ammaryasir786pk-a11y/fleetflow-vehicle-management/releases/latest/download/FleetFlow-Vehicle-Management-Windows.zip)**

The link always resolves to the asset with this filename in the latest published GitHub Release. To install, download the ZIP, extract all files to a folder, and run FleetFlow Vehicle Management.exe.

For the current release notes and SHA-256 checksum, see [Latest release](https://github.com/ammaryasir786pk-a11y/fleetflow-vehicle-management/releases/latest).

## Getting updates

When a newer Windows build is prepared, publish it as a new GitHub Release and upload the ZIP using the same filename above. Mark that release as the latest release. The download link on this page will then serve the new build automatically. Existing installed copies do not update themselves; users need to download and install the newer build.

This repository contains the public release page and packaged downloads. It does not contain the application source code.
